🌿 EcoPath – AI-Based Pollution-Aware Route Planner

Navigate Smarter. Breathe Better.

EcoPath is a web-based route planning application designed to bring environmental awareness into everyday travel planning. It combines route planning, map-based visualization and AI-powered assistance to help users make more informed travel decisions.

✨ Features

- Route Planning: Enter source and destination to plan a journey.
- Interactive Map: Visualize geographical locations and routes.
- AI Assistant: Get AI-generated travel guidance and pollution-related precautions.
- User Authentication: Register and log in using Supabase authentication.
- User Preferences: Set pollution sensitivity preferences for personalized guidance.

🛠️ Tech Stack

Technology| Purpose
React| User interface
TypeScript| Type safety
TanStack Start| Full-stack framework
Tailwind CSS| Styling
Supabase| Authentication and backend services
Leaflet| Interactive maps
OpenStreetMap / OSRM| Map data and route services
Google Gemini API| AI assistant
Vite| Development and build tooling

🚀 Getting Started

1. Clone the repository

git clone https://github.com/Mahima0324/ecopath-b9a700e2.git

2. Navigate to the project

cd Ecopath

3. Install dependencies

npm install

4. Configure environment variables

Create a ".env" file in the root directory and configure the Supabase and Gemini credentials using the exact variable names expected by the application.

Do not upload your ".env" file or private API keys to GitHub.

5. Run the development server

npm run dev

Open the local URL displayed in the terminal.

6. Build the application

npm run build
